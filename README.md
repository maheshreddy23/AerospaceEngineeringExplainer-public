# AerospaceEngineeringExplainer-public

Public files for the Aerospace Engineering Explainer channel, served with GitHub Pages:

- `/` homepage, `/privacy/`, `/terms/` (needed for the YouTube API audit)
- `/latest/` today's Shorts (the Instagram bio link). ClipBot writes `latest/shorts.json` after each post.

Code lives in the private repo. Nothing secret goes here.
