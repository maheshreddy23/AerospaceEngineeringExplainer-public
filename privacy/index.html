Privacy Policy

Effective 27 November 2026

This policy covers ClipBot, the posting tool of the Aerospace Engineering Explainer channel, and this website.

Who uses ClipBot

Only the channel owner. ClipBot is not offered to the public and no one else can sign in to it.

What data ClipBot accesses

  • YouTube (via YouTube API Services): permission to upload videos and manage comments on the owner's own channel, and nothing else. ClipBot does not read other users' data.
  • Google Drive: only a private backup copy of ClipBot's own settings.
  • Instagram (via the Instagram Graph API): permission to publish Reels, Stories and comments on the owner's own business account, and to read that account's own Stories to check they were posted.

What is stored, and where

  • A log of each published clip: source video id and time range, the published YouTube and Instagram ids, titles and captions. Kept in the owner's private GitHub repository, and, for published Shorts only, in this repository's public files for the "Latest Shorts" page.
  • Access credentials, kept privately in the owner's Google Drive and encrypted repository secrets. They are never published.

ClipBot collects no personal data from viewers. It sells nothing, shares nothing with third parties, and uses no advertising or tracking.

This website

This site is hosted on GitHub Pages and sets no cookies. GitHub may log visits as described in the GitHub Privacy Statement.

YouTube and Google

ClipBot uses YouTube API Services. By using this channel's content through YouTube you are bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. The owner can revoke ClipBot's access at any time at Google security settings; data is deleted from Drive on request or when the tool is retired.

Changes and contact

Changes are posted on this page with a new effective date. Questions: open an issue on GitHub.

This site and its posting tool use YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Contact: open an issue on GitHub.
